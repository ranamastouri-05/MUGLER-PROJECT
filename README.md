# MUGLER — Fashion & Fragrance

A React single-page showcase inspired by the Mugler fashion house. It introduces the house and its creative vision, highlights signature fashion and craftsmanship, and presents the Angel, Alien, and A*Men fragrances.

This is an educational frontend project. It is a static experience with no backend, shopping cart, or product purchasing functionality.

## Features

- Sticky navigation with links to the Home, About, Fashion, and Fragrance sections
- Hero section introducing the Mugler universe
- Brand story and designer introduction
- Fashion cards covering silhouettes, collections, and materials
- Fragrance cards featuring Angel, Alien, and A*Men
- Responsive styling and smooth section scrolling

## Built with

- React
- Vite
- CSS

## Getting started

You'll need Node.js and npm installed.

1. Open a terminal in this project folder.
2. Install the dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

   Open the local URL printed by Vite in your browser.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run Oxlint |

## Project structure

```text

  styles/       Main page styles
```
